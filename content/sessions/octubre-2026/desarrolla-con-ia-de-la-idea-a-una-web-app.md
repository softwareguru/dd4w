La Inteligencia Artificial está redefiniendo la forma en que desarrollamos software, permitiendo crear soluciones funcionales con mayor rapidez, calidad y confianza. En este taller práctico, las participantes descubrirán cómo aprovechar Cursor como asistente de desarrollo para construir una aplicación web utilizando Google Apps Script, una plataforma que permite crear y publicar soluciones sin necesidad de administrar servidores o infraestructura adicional.

A lo largo de la sesión exploraremos cómo la IA puede apoyar tareas como la generación de código, explicación de funciones, refactorización, resolución de errores y mejora continua del desarrollo, mientras construimos una aplicación completamente funcional.

El objetivo es que las asistentes conozcan un flujo de trabajo moderno donde la IA se convierte en una aliada para acelerar el desarrollo de software, reducir la curva de aprendizaje y facilitar la creación de soluciones reales con herramientas accesibles. Al finalizar, cada participante habrá publicado una aplicación web y contará con una base práctica para incorporar este tipo de asistentes inteligentes en sus propios proyectos.
